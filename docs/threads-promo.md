# Threads Promo Copy

## Version 1

유튜브에서 원하는 구간만 반복해서 보고 싶어서 크롬 확장 하나 직접 만들었습니다.

- 전체 반복
- A-B 구간 반복
- 반복 횟수 제한
- 영상별 설정 저장

## Version 2

YouTube Smart Looper라는 크롬 확장을 만들었습니다.
유튜브 영상에서 원하는 구간만 반복하거나, 전체 영상을 무한 반복할 수 있습니다.

- A-B loop
- Infinite loop
- 반복 횟수 제한
- 영상별 저장

써보고 싶은 분 있으면 반응 보고 공개 배포하겠습니다.

- 전체 반복
